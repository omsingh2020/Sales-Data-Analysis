# Sales Analysis Dashboard 📊

## Project Overview

The **Sales Analysis Dashboard** is an interactive Power BI project designed to analyze sales performance and provide meaningful business insights through data visualization.

The dashboard helps understand revenue distribution, sales quantity across different markets, revenue trends over time, and the performance of top customers and products.

It provides an overview of key sales metrics and allows users to explore the data using interactive year and date filters.

![Sales Analysis Dashboard](Sales%20dashboard.png)

## Key Features

- **Total Revenue:** Displays the overall revenue generated from sales.
- **Sales Quantity:** Shows the total quantity of products sold.
- **Revenue by Market:** Analyzes revenue generated across different markets.
- **Sales Quantity by Market:** Compares product sales quantities across different markets.
- **Revenue Trend:** Visualizes revenue changes over time to identify sales patterns.
- **Top 5 Customers:** Identifies the top five customers based on revenue.
- **Top 5 Products:** Highlights the top five products based on revenue.
- **Interactive Filters:** Allows users to filter the dashboard by year and date.

1. Delhi NCR contributes the highest revenue among the displayed markets.
2. Delhi NCR also records the highest sales quantity.

4. The top five customers contribute significantly to overall revenue.

## Project Objective

The main objective of this project is to transform raw sales data into an interactive dashboard that makes it easier to monitor business performance, identify important sales trends, and understand revenue distribution across different markets, customers, and products.
